# 📄 Computer Science Resume

LaTeX source code and compiled PDF for Thatcher Eames' Computer Science resume, tailored for software engineering and technical roles.

## 📌 Overview

This resume is designed to balance clean, modern visual formatting with high machine readability:
- **ATS-Optimized**: Configured with `glyphtounicode` and T1 font encodings to ensure accurate parsing by Applicant Tracking Systems.
- **Structured Layout**: Set in clean Helvetica sans-serif with sections for Education, Skills, Experience, Projects, and Awards.

## 📁 Files

- `ThatcherEames-Resume.tex` — Main LaTeX source file
- `ThatcherEames-Resume.pdf` — Compiled resume PDF

## 🛠️ Building

Compile the LaTeX source into a PDF using either `latexmk` or `pdflatex`:

**Using `latexmk`:**
```bash
latexmk -pdf ThatcherEames-Resume.tex
```

**Using `pdflatex`:**
```bash
pdflatex ThatcherEames-Resume.tex
```
